# Tutorials and Learning Resources

Authoritative documentation, guides, and lectures for understanding LLM agent planning and its failure
modes.

- **Building Effective Agents** — Anthropic Engineering Blog
  [anthropic.com/engineering/building-effective-agents](https://www.anthropic.com/engineering/building-effective-agents)
  Practitioner-oriented guide to agent design patterns (workflows vs. agents, augmented LLMs), directly
  relevant to why simple step-wise architectures under-perform on long-horizon tasks.

- **LangChain Academy**
  [academy.langchain.com](https://academy.langchain.com/)
  Structured, free courses on building agents with LangGraph, including memory and multi-agent
  orchestration modules.

- **DeepLearning.AI — LLMs as Operating Systems: Agent Memory**
  [deeplearning.ai](https://www.deeplearning.ai/short-courses/llms-as-operating-systems-agent-memory/)
  Short course built around the MemGPT/Letta approach to context and memory management.

- **Prompting Guide — Agents**
  [promptingguide.ai/research/llm-agents](https://www.promptingguide.ai/research/llm-agents)
  Continuously updated reference summarizing agent architectures, planning approaches, and their
  documented limitations, with links back to primary literature.

- **METR Blog**
  [metr.org/blog](https://metr.org/blog/)
  Ongoing publication of the time-horizon measurement methodology (Kwa et al., 2025) and related
  autonomous-capability evaluation work, useful for tracking how the field measures long-horizon
  competence over time.

Selection criteria: each resource is either an official vendor/lab publication, a maintained course
platform, or a continuously updated community reference tied back to primary research — not a
one-off blog post of unclear provenance.
