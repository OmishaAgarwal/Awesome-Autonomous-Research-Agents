# GitHub Implementations

Official or widely-cited reference implementations of the papers curated in this repository.

- **ReAct**
  [ysymyth/ReAct](https://github.com/ysymyth/ReAct)
  Official implementation accompanying Yao et al. (2023); interleaved reasoning-and-acting agent loop.
  Relevant as the foundational agent-control-loop implementation this field builds on.

- **Tree of Thoughts**
  [princeton-nlp/tree-of-thought-llm](https://github.com/princeton-nlp/tree-of-thought-llm)
  Official implementation accompanying Yao, Yu, et al. (2023); deliberate search over reasoning paths
  with backtracking, directly implementing the lookahead concept discussed in the paper.

- **Reflexion**
  [noahshinn/reflexion](https://github.com/noahshinn/reflexion)
  Official implementation accompanying Shinn et al. (2023); verbal self-critique and episodic memory
  for iterative self-correction.

- **Letta / MemGPT**
  [letta-ai/letta](https://github.com/letta-ai/letta)
  Actively maintained implementation of the MemGPT context-management approach (Packer et al., 2023).

- **Voyager**
  [MineDojo/Voyager](https://github.com/MineDojo/Voyager)
  Official implementation accompanying Wang, Xie, et al. (2023); persistent skill-library agent for
  lifelong learning in Minecraft, illustrating context-decoupled competence.

- **SWE-bench**
  [princeton-nlp/SWE-bench](https://github.com/princeton-nlp/SWE-bench)
  Official benchmark harness accompanying Jimenez et al. (2024); actively maintained with a public
  leaderboard, well-documented setup, and reproducible evaluation scripts.

- **AI-Scientist**
  [SakanaAI/AI-Scientist](https://github.com/SakanaAI/AI-Scientist)
  Official implementation accompanying Lu et al. (2024); end-to-end automated research pipeline, and the
  direct subject of the methodological-drift audit by Luo, Kasirzadeh, & Shah (2025).

Selection criteria applied: each repository is the official implementation tied to a peer-reviewed or
arXiv paper cited above, is actively maintained or archived with clear documentation, and directly
illustrates a mechanism or mitigation strategy discussed in the paper (not selected merely by star
count).
